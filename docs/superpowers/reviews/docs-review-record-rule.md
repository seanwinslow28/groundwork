# Codex review record — branch `docs/review-record-rule`

> The durable per-round review log rule 9 requires, kept on the branch that installs
> rule 9. Plan-less work uses this location (`docs/superpowers/reviews/<branch>.md`,
> `/` written as `-`); slices with a plan use `docs/superpowers/plans/<slice>-reviews.md`.
> Every round is appended here before the branch may merge: verdict, each finding with
> severity and CONFIRMED/PLAUSIBLE status, and its disposition. Amendments are
> append-and-supersede — a prior round's table is never rewritten.
