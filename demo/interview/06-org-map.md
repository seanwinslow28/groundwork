# Layer 6 — The org map: who holds what, and how often that gets re-checked

**Not a function layer.** Layers 02 to 05 each mapped a function; layer 01 set the
analyst's role and the company's scope. This one is about the record itself: the owners those layers named, what kind of thing each one is,
and when the answer should be looked at again. It was run because the roster generated
from layers 01–03 had never been re-confirmed since May, and because the question skeleton

## Re-confirmation cadence

**Quarterly.** Priya's reasoning, recorded because the number on its own says nothing: at
twenty people the map is small enough to re-read in ten minutes, and the thing that
actually changes it — somebody leaving, or a function changing hands — happens once or
twice a year and is never announced to a file. Quarterly is short enough that the gap
between the change and the record is a season rather than a year, and long enough that
nobody starts ignoring the prompt.

Annual was considered and rejected for the second reason in that sentence: the demo has
already run one full quarter past a ninety-day default without anybody noticing, which is
the failure a longer cadence makes cheaper rather than rarer.
